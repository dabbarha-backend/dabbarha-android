# دبّرها — Backend

هذا هو خادم الذكاء الاصطناعي لتطبيق دبّرها.

## إعداد Render

Root Directory:

backend

Build Command:

npm install

Start Command:

node server.js

## Environment Variables

أضف في Render:

GEMINI_API_KEY

ثم أضف:

GEMINI_MODEL

واجعل قيمته:

gemini-2.5-flash

## ملاحظة مهمة

لا تضع GEMINI_API_KEY داخل التطبيق أو داخل GitHub.

المفتاح يجب أن يبقى محفوظًا في Environment Variables داخل Render.
